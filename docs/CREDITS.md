# Credits

## Lighting environments

The eight real lighting environments in `public/env/` are HDRIs from
[Poly Haven](https://polyhaven.com), released under CC0 — no attribution is
required, and we give it anyway. Each is the 1K version, fetched by
`pnpm fetch:env`.

| In the tool | Poly Haven asset |
| --- | --- |
| Studio soft | [studio_small_09](https://polyhaven.com/a/studio_small_09) |
| Studio hard | [studio_small_03](https://polyhaven.com/a/studio_small_03) |
| Photo studio | [brown_photostudio_02](https://polyhaven.com/a/brown_photostudio_02) |
| Warehouse | [empty_warehouse_01](https://polyhaven.com/a/empty_warehouse_01) |
| Overcast sky | [kloofendal_48d_partly_cloudy_puresky](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky) |
| Sunset | [venice_sunset](https://polyhaven.com/a/venice_sunset) |
| City | [potsdamer_platz](https://polyhaven.com/a/potsdamer_platz) |
| Night | [moonless_golf](https://polyhaven.com/a/moonless_golf) |

The other eight environments are gradients the engine paints at runtime; no
files, no credit needed.
